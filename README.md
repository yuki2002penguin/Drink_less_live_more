# Alcohol Habit Control App - DRINKLESS & LIVEMORE - Prototype

A single-page application (SPA) prototype for an alcohol habit control and dry-day management system, designed with a monochrome minimalist user interface.

## Features
* **Multi-Language Support**: Built-in toggle for seamless switching between English and Japanese.
* **Detailed Analytics**: Tracks current streak, success rate, and a 4-week dry day breakdown chart.
* **Smartwatch Integration**: Includes Apple Watch interface simulations with dedicated smartwatch iconography.
* **Flow Controller**: A sidebar console allowing instant navigation across 13 core screens (from Onboarding to Rewards Vault).
